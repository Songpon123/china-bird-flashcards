# 羽 Yǔ · คู่มือใช้งานแฟลชการ์ดชื่อนกจีน

แอปฝึกชื่อจีนตัวย่อ พินอินพร้อมวรรณยุกต์ ชื่ออังกฤษ และชื่อวิทยาศาสตร์ เมนูและปุ่มเป็นภาษาอังกฤษ มีคำอธิบายศัพท์ภาษาไทยประกอบ ไม่ต้องสมัครบัญชีหรือใส่ API key

**[เปิดแอปบนมือถือ / iPad / คอมพิวเตอร์](https://songpon123.github.io/china-bird-flashcards/)** · [โค้ดบน GitHub](https://github.com/Songpon123/china-bird-flashcards) · [คู่มือและรายละเอียดทางเทคนิค](README.md)

## เริ่มใช้บนมือถือหรือ iPad

เปิดลิงก์แอปด้านบนด้วย Safari หรือเบราว์เซอร์สมัยใหม่ หน้าเว็บต้องใช้อินเทอร์เน็ตตอนโหลด การเพิ่มไว้ที่หน้าจอโฮมไม่ได้ทำให้รุ่นนี้รองรับออฟไลน์โดยอัตโนมัติ

1. ที่ **Study** เลือก **Card deck** เป็น **Species** หรือ **Families & groups**
2. เลือก **Study direction** เป็น **Chinese → English** หรือ **English → Chinese**
3. นึกคำตอบ แล้วกด **Reveal answer** ปุ่มจะเปลี่ยนเป็น **Show question**
4. หลังเฉลยการ์ดชนิดนก จะมี **View on eBird ↗** สำหรับเปิดข้อมูลนกในแท็บใหม่ คำถามเดิมและความคืบหน้ายังคงอยู่ในแอป
5. กด **Again / Hard / Good / Easy** เพื่อกำหนดเวลาทบทวนครั้งต่อไป หรือเลือก **Browse & practice freely** เพื่อฝึกโดยไม่เปลี่ยนตารางทบทวน

**หมายเหตุลิงก์ eBird:** มีลิงก์อ้างอิง 1,418 ชื่อ แบ่งเป็นชื่อวิทยาศาสตร์ตรงกัน 1,274 ชื่อ นามพ้องตรงกัน 22 ชื่อ และชื่ออังกฤษตรงกัน 122 ชื่อ กลุ่มสุดท้ายจะแสดง **Name-based reference** พร้อมชื่อปลายทาง เพราะอนุกรมวิธานของแต่ละแหล่งอาจต่างกัน อีก 27 ชื่อใช้ **Find on eBird ↗** เพื่อเปิดหน้า Explore แล้วค้นหาเอง การ์ดวงศ์และกลุ่มไม่มีลิงก์ไปยังนกชนิดใดชนิดหนึ่ง

## การแก้ชื่อตาม AviList v2026

แก้การ์ด 46 ใบที่มีชื่อใดชื่อหนึ่งเป็นของนกคนละชนิดกับนกที่พบในจีน เช่น 喜鹊 เดิมเขียนว่า Eurasian Magpie (*Pica pica*) ตอนนี้เป็น Oriental Magpie (*Pica serica*) และ 牛背鹭 เดิมเขียนว่า Western Cattle Egret ตอนนี้เป็น Eastern Cattle Egret (*Ardea coromanda*) การ์ดทุกใบยังใช้ ID เดิม ความคืบหน้าที่บันทึกไว้จึงไม่หาย รายละเอียดและหลักฐานของแต่ละรายการอยู่ใน `source-notices/name-corrections-2026-11.json`

## ดูความหมายและที่มาของชื่อ

เปิด **Name guide** หรือหลังเฉลยแล้วเปิด **Understand this name · meanings & story** เพื่ออ่านคำอธิบาย เช่น **白 (bái)** หมายถึงขาว และ **鹭 (lù)** หมายถึงนกยาง

- ชื่อสถานที่และคำที่อ่านเป็นคำเดียว 48 คำ เช่น 日本 (ญี่ปุ่น), 四川 (เสฉวน), 喜山 (หิมาลัย), 八哥 (นกเอี้ยง), 孔雀 (นกยูง) แสดงความหมายของทั้งคำ เช่น 日本松雀鹰 อ่านว่า ญี่ปุ่น + เหยี่ยว ส่วนอักษรหน้า 氏 เป็นชื่อบุคคล เช่น 理氏 = “ของริชาร์ด”
- มีความหมายอังกฤษสำหรับอักษรจีนทั้ง 475 ตัวที่ใช้ในข้อมูลชุดนี้ พร้อมคำแปลไทยช่วยเรียน 236 ตัว
- คำประสม 49 คำมีพินอินครบคำ เช่น **鹡鸰 (jí líng)** และ **伯劳 (bó láo)**
- มีคำอธิบายชื่อที่คัดเลือก 10 รายการ แยกคำแปลตามตัวอักษร การใช้คำ ความเชื่อ และตำนาน พร้อมแหล่งอ้างอิง ไม่ได้ยืนยันประวัติการตั้งชื่อครบทุกชนิด
- **Families & groups** มี 26 วงศ์และ 7 กลุ่มช่วยเรียน เช่น เหยี่ยว นกเขา–นกพิราบ เป็ด และห่าน กด **View species** เพื่อดูนกในกลุ่ม

## เก็บและย้ายความคืบหน้า

ความคืบหน้าเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่มีการซิงก์บัญชีอัตโนมัติ ใช้ **My progress → Download full backup** เพื่อสำรอง แล้วใช้ **Data & sources → Restore a full backup** ที่อีกเครื่อง มีตัวอย่างข้อมูลให้ตรวจสอบก่อนแทนที่ข้อมูลเดิม

ความคืบหน้าบนเว็บ GitHub Pages และบนเว็บที่เปิดจากเครื่องตัวเองเป็นคนละชุด เช่นเดียวกับคนละเบราว์เซอร์ การล้างข้อมูลเบราว์เซอร์อาจทำให้ความคืบหน้าหาย จึงควรเก็บไฟล์สำรองไว้

## เปิดจากโฟลเดอร์โปรเจกต์บนคอมพิวเตอร์

ต้องมี Node.js รุ่น 18 ขึ้นไป เปิด Terminal ในโฟลเดอร์ `china-bird-flashcards` แล้วรัน:

```sh
npm start
```

จากนั้นเปิด **http://127.0.0.1:4173** ไม่ต้องรัน `npm install` และต้องเปิด Terminal ค้างไว้ระหว่างใช้งาน หยุดด้วย Ctrl+C อย่าเปิด `index.html` ตรง ๆ เพราะเบราว์เซอร์จะจำกัดการโหลดข้อมูล

ทดสอบโปรเจกต์ด้วย:

```sh
npm test
```

## ไฟล์สำคัญในโฟลเดอร์

| ไฟล์ / โฟลเดอร์ | เนื้อหา |
| --- | --- |
| `index.html`, `app/` | หน้าเว็บ รูปแบบ และระบบฝึก |
| `data/birds.json` | ชนิดนกและชื่อจากแหล่งอ้างอิง |
| `data/groups.json` | ชื่อวงศ์และกลุ่มพร้อมขอบเขตสมาชิก |
| `data/name-guide.json` | ความหมายอักษร พินอิน และคำอธิบายชื่อ |
| `data/ebird-links.json` | ลิงก์อ้างอิงชนิดนกบน eBird |
| `scripts/` | โปรแกรมเปิดเว็บและสร้างข้อมูลซ้ำ |
| `source-notices/` | ข้อมูลอ้างอิง เครดิต และเงื่อนไขแหล่งข้อมูล |
| `tests/` | การทดสอบข้อมูลและการทำงานสำคัญ |
| `SOURCES.md`, `DATA_LICENSE.md` | ที่มาข้อมูล ข้อจำกัด และสิทธิ์การใช้ |
